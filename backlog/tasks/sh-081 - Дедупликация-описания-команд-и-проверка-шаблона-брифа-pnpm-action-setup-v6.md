## Зачем
SH-080 ввела шаблон брифа и команды `pnpm sync` и `pnpm status`. Ревью той задачи нашло, что описание команд теперь лежит в трёх файлах: при изменении флага придётся править три места, и они разойдутся. Замечание оставили как есть, чтобы не раздувать SH-080. Шаблон брифа написан, но не проверен на настоящих брифах: он экономит контекст штаба и сессии, только если сессии хватает его без уточнений. Пункт про `pnpm/action-setup` добавили в эту задачу по просьбе владельца (2026-11-12) после предупреждения GitHub в проверке `checks`: предупреждение не ломает CI, но старая версия перестанет работать, когда Node 20 уберут с раннеров. Пункт не связан с первыми двумя по теме.
