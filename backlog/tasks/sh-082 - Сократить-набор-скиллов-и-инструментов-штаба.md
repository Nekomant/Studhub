## Зачем
Штаб и рабочие сессии грузят около 200 скиллов из шести плагинов аккаунта. Плагины, которые отключаем, дают около 8–11 тыс. токенов из ~58 тыс. в начале сессии приложения. Из плагинов проекту нужен только `mattpocock-skills` (`grilling`, `research`, `domain-modeling`). Остальные заточены под другой стек (Vue, Tabler, TypeORM) или навязывают свои TDD, планы, handoff и процесс работы с ветками, которые спорят с `docs/process.md`. Агент `sh-worker` плагины не грузит, поэтому выигрыш идёт штабу и сессиям задач. Блок «Закрытие» в `sh-task` дублирует §7.1 и зря попадает в контекст `sh-worker`.

## Контекст
- Процесс: `docs/process.md` §4, §5, §7, §7.1
- Предыдущая экономия контекста: SH-077, SH-080
- Формат ключей плагинов проверен командой `claude plugin list`: `<имя>@synced`
- Замер «до» (сессия приложения, `/context`, 2026-11-12): всего 58,4 тыс. токенов. Инструменты MCP 16,6 тыс., системные инструменты 14,3 тыс., системный промпт 11,2 тыс., скиллы 9,9 тыс., файлы памяти 2,8 тыс., агенты 2,8 тыс., инструкции MCP 0,7 тыс. Отложенные инструменты (только имена): MCP 50,1 тыс., системные 25,6 тыс., в сумму не входят.

## Не входит
- Личные настройки `~/.claude`, правка самих плагинов.
- Новый скилл для спецификаций штаба: вместо него строка в `CLAUDE.md` (пункт 5), чтобы не плодить второй источник шаблона.
- Экономия токенов в `sh-worker` и `sh-verifier`.

## Контракт
API и БД не меняются. Меняются `.claude/settings.json`, `.claude/skills/sh-task/SKILL.md`, `CLAUDE.md`, `docs/process.md`; добавляется тест в `tools/tests`.
