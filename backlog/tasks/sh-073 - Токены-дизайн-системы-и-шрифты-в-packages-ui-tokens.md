## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## Что нужно сделать
1. Создать `packages/ui-tokens`: CSS-переменные всех токенов `design-system.md` (цвета обеих тем, отступы, радиусы, высоты, тени, стили текста).
2. Сделать переключение темы: без класса на `<html>` тема следует `prefers-color-scheme`, классы `dark` и `light` её переопределяют.
3. Описать тему Tailwind CSS v4 на этих переменных и задать переменные shadcn/ui по таблице §8.
4. Положить в пакет шрифты Nunito 800 и Manrope 300, 400, 600 в `woff2` с подмножествами latin и cyrillic, подключить через `@font-face`.
5. Сделать страницу-образец пакета для визуальной проверки владельцем.
6. Написать тесты по критериям.

## Зачем
Внешний вид согласован (`docs/design-system.md`, решения ДС-1…ДС-8), но в коде его ещё нет. Каркас SPA (SH-008) и лендинг (SH-015) должны с первого дня брать цвета, шрифты и размеры из одного пакета, иначе значения разойдутся по файлам, а тёмную тему придётся доделывать по всем экранам. Пакет общий для `apps/web` и `apps/landing` (ТД §2.4).

## Контекст
- `docs/design-system.md`: §3 цвета, §4 статусы, §5 шрифты, §6 размеры, §8 соответствие shadcn/ui.
- ТД §3 (UI-стек), §9 (без внешних CDN, шрифты раздаём сами), §2.4 (`packages/ui-tokens`).
- Визуальные образцы: артефакты дизайн-системы и макетов по ссылкам в `design-system.md` §1 (открывает только владелец, все значения есть в документе).

## Не входит
- Компоненты shadcn/ui и оболочка приложения: SH-008 и задачи экранов.
- Переключатель «Оформление» в Э-17: SH-022.
- Вёрстка лендинга: SH-015.
