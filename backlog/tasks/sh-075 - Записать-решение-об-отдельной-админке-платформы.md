## Зачем
Владелец решил, что админка понадобится и её нужно предусмотреть заранее, а делать на стадии 2 (закрытая бета). В документах сейчас админка — раздел SPA преподавателя с флагом `is_platform_admin`, и модель пользователей (SH-016) заложит этот флаг, если не поправить документы до неё.

## Решения (согласованы с владельцем 2026-11-11)
1. Отдельное приложение `apps/admin` на `admin.studentshub.ru`. API `/api/admin/v1` в том же `apps/api`, со своей спецификацией OpenAPI и своим сгенерированным клиентом. Админ работает через функции модулей, правила домена общие.
2. Сотрудник видит все кабинеты. ПДн учеников маскирует сервер: имя → «Ученик 7F3A», телефон, Telegram, email и место встречи → последние 2 символа. Заметки, итог, план, ДЗ, цели, описания и файлы материалов скрыты: видно только наличие, длину и дату. Деньги, цены, статусы, даты, слоты, тариф, счётчики и технические ID открыты. Снять маску нельзя. Для поиска ученика у преподавателя есть кнопка «Скопировать ID для поддержки».
3. Вход: Яндекс ID или VK ID, затем TOTP. Cookie `sh_admin_session` только на поддомене админки, 8 часов без продления. Команды, которые что-то меняют, снова просят код TOTP.
4. Таблица `platform_staff`: `user_id`, `role` (`superadmin` | `support`), зашифрованный секрет TOTP, `created_at`, `disabled_at`. `superadmin` может всё, включая тарифы, удаление и управление сотрудниками. `support` читает и выполняет безопасные команды. Роли кабинета (`workspace_member.role`) и роли платформы независимы.
5. `admin_audit` пишет каждый запрос к `/api/admin/v1`: сотрудник, сессия, действие, тип и ID объекта, `workspace_id`, результат (`ok` | `denied` | `error`), IP и браузер сотрудника, время, для команд `details jsonb` без ПДн. Запись в той же транзакции, что и команда. У приложения право только на `INSERT`. Хранение 1 год.
6. Данные преподавателя открыты: имя, email, провайдеры входа (без ID у провайдера), часовой пояс, тариф, дата регистрации, статус удаления. Основание: поддержка клиентов как цель в политике обработки.
7. В MVP экрана метрик нет. SH-065 делает события и представления `analytics`, метрики владелец смотрит через `scripts/metrics.sql` по SSH. Э-18 становится первым экраном каркаса админки.
