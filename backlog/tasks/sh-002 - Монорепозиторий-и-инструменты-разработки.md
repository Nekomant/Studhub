## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Корень: package.json (pnpm 12.18.0, Node >=24), pnpm-workspace.yaml, .nvmrc 24, .editorconfig, .gitignore.
2. Пакеты по ТД §13: apps/api, apps/web, apps/landing, packages/client-core, packages/ui-tokens, tests/api, tests/e2e с package.json и src-заглушкой.
3. TypeScript 6 strict: tsconfig.base.json, composite-проекты в TS-пакетах, корневой tsconfig.json со ссылками; web и tests/api ссылаются на client-core.
4. Biome: формат и линт, правила границ ТД §13 через noRestrictedImports в overrides. Опции правила в overrides заменяются, а не складываются, поэтому каждый блок содержит полный набор запретов для своих файлов.
5. Фикстуры tools/boundary-fixtures/ повторяют пути репозитория: файлы-нарушения и разрешённые импорты. Тест копирует их с biome.json во временную папку, запускает Biome и сверяет ошибки по каждому файлу. Обычный pnpm check фикстуры не проверяет.
6. Vitest: корневой конфиг с projects. lefthook: pre-commit запускает Biome по staged-файлам, commit-msg запускает scripts/check-commit-msg.mjs (свой скрипт на 20 строк вместо commitlint, типы из process.md §9).
7. Скрипты pnpm check (biome ci + tsc -b) и pnpm test (vitest run). README.
8. Тесты с метками [SH-002 AC-n] пишем до реализации: AC-1 структура, AC-2 фикстуры, AC-3 скрипт commit-msg и lefthook.yml, AC-4 README и .nvmrc. Ручные проверки: AC-1 на чистом клоне, AC-3 настоящий коммит.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Оценка: 6 ч

Решения:
- Node 24 (nvm, 24.22.2) и pnpm 12.18.0 (поле packageManager). В Node 24.22 нет corepack, pnpm ставим через npm i -g, это в README.
- TypeScript 6.0.3, а не 7.0: @astrojs/check и openapi-typescript пока не поддерживают TS 7.
- Проверка сообщения коммита: свой скрипт scripts/check-commit-msg.mjs (типы из process.md §9) вместо commitlint, чтобы не добавлять инструмент. ID задачи хук не требует: этого нет в AC-3.
- Biome: опции noRestrictedImports в overrides заменяются, а не складываются, поэтому каждый блок перечисляет все запреты для своих файлов. Правило 4 узнаёт свой модуль по форме пути до четырёх ../. Импорты из platform/ разрешены, platform/db только из */db/.
- Biome 2.6 форматирует Markdown и переформатировал бы docs/, поэтому *.md исключены из Biome.
- pnpm 12 падает на неразрешённых build-скриптах: в pnpm-workspace.yaml allowBuilds lefthook: false, хуки ставит скрипт prepare.
- Git-хуки общие для всех worktree (.git/hooks). На main без lefthook.yml хук ничего не делает (проверено: lefthook run commit-msg в основной папке, код 0).
