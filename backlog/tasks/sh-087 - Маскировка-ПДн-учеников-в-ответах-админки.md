## Что нужно сделать
1. Написать юнит-тесты по критериям до реализации.
2. Сделать в `apps/api` единое место маскировки для ответов `/api/admin/v1` (модуль `admin`, слой `domain`, чистые функции без БД и HTTP). Правила по ADR-0009, п. 2:
   - имя ученика → «Ученик 7F3A», где `7F3A` берётся из технического ID ученика и стабильно;
   - телефон, Telegram, email и место встречи → последние 2 символа;
   - заметки, итог и план урока, ДЗ, цели, описания и файлы материалов скрыты: в ответе только признак наличия, длина и дата;
   - деньги, цены, статусы, даты, слоты, тариф, счётчики и технические ID открыты.
3. Дать эндпоинтам админки способ вернуть ученика или урок только через эти функции: в схемах ответов `/api/admin/v1` нет полей с открытыми ПДн учеников.
4. Сделать автоматическую проверку: тест обходит схему OpenAPI админки и падает, если в ответе есть поле из списка «ПДн ученика» без пометки о маскировке.
5. Данные преподавателей (имя, email, провайдеры входа без ID у провайдера, часовой пояс, тариф, дата регистрации, статус удаления) оставить открытыми и описать в этом же модуле как явно разрешённый список.
6. Описать в ТД §9 соответствие правил маскировки коду.

## Зачем
Админка читает все кабинеты. Если браузер получает открытые ПДн учеников, угон одной учётки раскрывает всех учеников всех преподавателей. Маскировка на сервере в одном месте делает это невозможным по построению (ADR-0009, п. 2).

## Контекст
- Решение: ADR-0009, п. 2 и «Последствия» (маскировка в одном месте, тест на отсутствие ПДн).
- Правила: ТД §9 (минимизация ПДн, админка), §4.2 (`platform_staff`).
- Зависит от SH-084 (модуль `admin` и спецификация `/api/admin/v1`).

## Не входит
- Эндпоинты со списками учеников и кабинетов: отдельные задачи стадии 3 используют эту маскировку.
- Снятие маски по причине: возможное расширение ADR-0009, не делаем.
- Кнопка «Скопировать ID для поддержки» в `apps/web`: отдельная задача.

## Контракт
Нет внешнего API. Внутренний интерфейс модуля `admin` `domain/masking`: функции маскировки имени, контактов, свободного текста и вложений.

| 1 | Юнит | имя маскируется как «Ученик XXXX», один ID даёт один результат, разные ID разные |
