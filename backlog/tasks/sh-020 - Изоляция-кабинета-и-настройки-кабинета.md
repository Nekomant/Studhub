## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## Что нужно сделать
1. До реализации написать общий тест изоляции, который читает `openapi.json` и обходит все эндпоинты кабинета, и API-тесты остальных критериев.
2. Реализовать middleware `/api/v1/workspaces/{wid}/…`: проверка членства, формирование `ctx`, 404 для чужого и несуществующего кабинета.
3. Ввести правило «репозитории принимают `ctx`» и оформить пример в модуле `workspaces`.
4. Реализовать `GET/PATCH /workspaces/{wid}` и `PATCH /me` с проверками полей.
5. Добавить справочник валют с числом знаков после запятой.
6. Проверить тест изоляции на фикстуре эндпоинта без проверки членства.

## Зачем
Изоляция арендатора держится на коде (ADR-0003), поэтому её страхует автоматический тест по всем эндпоинтам. Настройки кабинета — значения по умолчанию для учеников и политики отмены.

## Контекст
- Сценарии: UC-09.
- Экраны: Э-17 «Кабинет», «Профиль».
- Правила: ТД §4.1–4.2, §6.1, ADR-0003.

## Не входит
- Смена зоны с пересчётом слотов (`slotsMode`, `dryRun`) — задача этапа 3 «Смена часового пояса».
- Экраны настроек — задача «Настройки и онбординг: шаг 1».

## Контракт
- `GET /api/v1/workspaces/{wid}` → `{ id, name, plan, defaultCurrency, defaultTimezone, lateCancelWindowHours, lateCancelChargePct, noShowChargePct, storage: { usedBytes, limitBytes } }`.
- `PATCH /api/v1/workspaces/{wid}` — те же поля, кроме `plan`, `storage`.
- `PATCH /api/v1/me` `{ displayName?, timezone? }`.
- Ошибки: 404 (чужой кабинет), 422 с ошибками по полям.

## План тестов
| AC | Уровень | Тест |
|---|---|---|
| 1 | API | чужой и несуществующий wid → 404 с одинаковым телом |
| 2 | API | обход всех `/workspaces/{wid}/…` из openapi.json; фикстура эндпоинта без проверки → тест красный |
| 3 | API | GET кабинета |
| 4 | API | PATCH: граничные значения 0/168, 0/100, неизвестная валюта |
| 5 | API | PATCH /me: имя 0/1/100/101, невалидная зона |

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Запрос к ресурсу чужого или несуществующего кабинета → 404 с одинаковым телом ответа (существование кабинета не раскрывается)
- [ ] #2 Тест изоляции автоматически проходит все эндпоинты `/workspaces/{wid}/…` из `openapi.json` с сессией другого пользователя и ожидает 404; эндпоинт без проверки членства делает тест красным
- [ ] #3 `GET /workspaces/{wid}` возвращает название, тариф, настройки по умолчанию и хранилище (занято 0 из 20 ГБ для `beta`)
- [ ] #4 `PATCH /workspaces/{wid}` меняет название (1–100 символов), валюту по умолчанию (только из справочника), окно поздней отмены (0–168 ч) и проценты списания (0–100); неверные значения → 422 с ошибками по полям
- [ ] #5 `PATCH /me` меняет имя (1–100 символов) и часовой пояс (только существующая IANA-зона)
<!-- AC:END -->
