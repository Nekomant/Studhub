## Зачем
Сейчас запуск задачи ведёт штаб на Opus: проверяет Ready, создаёт ветку, запускает сессию и `sh-worker`, разбирает ответ. Это работа по жёстким правилам, и каждый шаг тратит контекст и запросы Opus. Фабрика делает то же локальным скриптом без модели. Эта задача — первая часть: выбор задачи, ветка, worktree и состояние; запуск воркера — SH-098. Владелец запускает её одной командой из терминала, а штаб остаётся для спецификаций и решений.
