## Что нужно сделать
1. Завести закрытый список событий, `POST /events` и серверные события.
2. Создать SQL-представления в схеме `analytics` по ТД §11.
3. Написать `scripts/metrics.sql`: запросы ко всем представлениям, которые владелец запускает на prod по SSH.
4. Написать тесты.

## Зачем
Критерии перехода стадий (активность, доля открытых уроков) должны измеряться. До стадии 3 пользователей 1–20, и SQL-запроса хватает: экран метрик переехал в каркас админки (ADR-0009).

## Контекст
- Сценарии: UC-P1.
- Правила: ТД §4.9 (`product_event`), §11; ADR-0009.

## Не входит
