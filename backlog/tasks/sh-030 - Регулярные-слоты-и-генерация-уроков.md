## Что нужно сделать
1. Описать таблицы `recurring_slot`, `slot_participant`, `lesson`, `lesson_participant` и миграции.
2. Реализовать в `schedule/domain` генерацию уроков по слоту с учётом зон и перевода часов (ТД §5.1–5.2), покрыть юнит-тестами.
3. Реализовать API создания слота с генерацией в той же транзакции.
4. Добавить ночную задачу pg-boss, продлевающую горизонт генерации.
5. Написать API-тесты.

## Зачем
Регулярное расписание — основа недели репетитора; уроки хранятся строками на горизонт.

## Контекст
- Сценарии: UC-17, UC-S1.
- Правила: ТД §4.4, §5.1 (часовые пояса, перевод часов), §5.2, ADR-0005.
