# /ready: запуск задачи фабрикой

Команда `/ready SH-NNN` или `/ready` без номера. Скилл готовит задачу фабрикой, открывает подсессию воркера и доводит задачу до слияния по добру владельца. Источник: `docs/process.md` §7.1, ADR-0011.

## Порядок

1. Номер принимай только в виде `SH-NNN`, регистр не важен. Другой ввод не угадывай: спроси владельца, какую задачу запустить.
2. Запусти `pnpm factory ready` (с номером — `pnpm factory ready SH-NNN`). Команда выбирает задачу в Ready, проверяет Definition of Ready и актуальность по git, готовит ветку и worktree, записывает права и модель воркера в настройки worktree и печатает бриф.
3. Успех: код 0 и в выводе есть бриф с ID задачи, веткой и путём к worktree. Открой подсессию одним вызовом `start_session` в worktree задачи и передай бриф: ID задачи, ветка, путь к worktree. Процесс не пересказывай — воркер знает его.
4. Код не 0: покажи вывод владельцу и остановись.
5. Дальше работает воркер в подсессии: пишет тесты и код и вызывает `factory next`. Текущий этап показывай фразой из `pnpm factory status SH-NNN`.
6. Когда владелец напишет, что готов слить, вызови `pnpm factory merge SH-NNN`: фабрика коммитит статус Merged, сливает PR squash, удаляет ветку и worktree и подтягивает main.
7. После слияния архивируй подсессию (`archive_session`).

## Запреты

- За одну команду запускай одну задачу. Цикла по списку нет; одновременно в работе одна задача.
- Не вызывай `pnpm factory ready` без номера, если не готов сам выбрать кандидата из списка фабрики.
