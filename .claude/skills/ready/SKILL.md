# /ready: запуск задачи фабрикой

Команда `/ready SH-NNN` или `/ready` без номера. Скилл запускает одну задачу и не открывает сессию для воркера. Воркер идёт фоновым процессом, его запускает фабрика ([README.md](../../../README.md#запуск-задачи-pnpm-factory), ADR-0010).

## Порядок

1. Номер принимай только в виде `SH-NNN`, регистр не важен. Другой ввод не угадывай: спроси владельца, какую задачу запустить.
2. Номер указан: запусти `pnpm factory run SH-NNN`.
3. Номер не указан: запусти `pnpm factory list`. Кандидаты это только строки до блока `Ждут зависимость:`; строки блока кандидатами не считай и не запускай.
   - Кандидатов нет: ответь «Задач в Ready нет», покажи блок `Ждут зависимость:`, если он есть, и остановись.
   - Один кандидат: запусти `pnpm factory run SH-NNN` для него.
   - Несколько кандидатов: покажи список, спроси номер задачи и запусти `pnpm factory run SH-NNN` для выбранной.
4. Запускай `pnpm factory run` с таймаутом 10 минут: команда готовит ветку и worktree и ставит зависимости. После подготовки воркер идёт фоном, а команда сразу завершается.
5. Успех: код 0 и в выводе есть строка `SH-NNN: воркер запущен`. Ответь одной строкой: ID, ветка, путь к журналу. Бери их из строк `Ветка:` и `Журнал:` вывода.
6. Код `list` или `run` не 0 (в том числе лимит двух живых процессов или задача не кандидат), либо в выводе `run` нет строки «воркер запущен»: покажи вывод владельцу и остановись.

## Запреты

- Не вызывай `pnpm factory run` без номера: команда спросит ввод и зависнет.
- За одну команду запускай одну задачу. Цикла по списку нет.
- Остановки воркера, вопросы и ответы не входят в скилл (SH-094).
