# ADR-0006: Вход только через Яндекс ID и VK ID

- Статус: принято
- Дата: 2026-11-11

## Контекст

Пользователь должен войти с минимумом действий. Статья 10.6 закона 149-ФЗ (в редакции 406-ФЗ, действует с 1 декабря 2023 года) запрещает российским сайтам авторизацию через зарубежные сервисы (Google, Apple). Почтовый сервис в MVP подключать не хотим.

## Решение

- OAuth 2.0 + PKCE с Яндекс ID и VK ID. Реализация своя (или на `arctic`), без готовой auth-библиотеки.
- Регистрация и вход — одно действие. При первом входе показываем экран отдельных согласий (ПДн и оферта).
- Сессия — случайный токен, в таблице `session` хранится его SHA-256. Cookie `httpOnly`, `Secure`, `SameSite=Lax`, срок 90 дней со скользящим продлением. Bearer-токены — через ту же таблицу.
- `auth_identity` позволяет привязать второй провайдер. Автосвязка по email — только если провайдер подтвердил email.

## Последствия

- Писем нет: напоминания только внутри приложения.
- Если пользователь потерял аккаунт провайдера, доступ восстанавливается через второй привязанный провайдер или поддержку. Поэтому привязку второго провайдера предлагаем в интерфейсе.
- Нужно проверить OAuth в установленной PWA на iOS (отдельное хранилище cookie).
- Код по email, Telegram Login и passkey добавляются новыми провайдерами без изменения схемы.
- Юридическую трактовку 406-ФЗ проверяет юрист до стадии 3.
