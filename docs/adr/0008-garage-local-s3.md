# ADR-0008: Garage вместо MinIO локально, без версионирования файлов

- Статус: принято
- Дата: 2026-11-11

## Контекст

ТД предполагал MinIO как локальный S3 и версионирование бакета на 30 дней в prod. К моменту задачи SH-003 официальные образы MinIO перестали публиковаться на Docker Hub (последние сообщения о выпусках относятся к осени 2025), проект перешёл в режим обслуживания или архивирован. Образ клиента `mc` тоже недоступен. Брать неофициальные зеркала для разработки мы не хотим. При этом файлы нужны только как S3 API: presigned PUT и GET, `HEAD`, `GET Range`, удаление.

## Решение

- Локальный S3 — Garage (`dxflrs/garage`, одна нода). Образ запускается с `--single-node --default-bucket`: бакет и ключ создаются при старте, отдельный контейнер для этого не нужен. Конфиг — `infra/garage/garage.toml`, регион `garage`, адресация по пути.
- Версионирование бакета и правило удаления старых версий не используем. Удаление материала необратимо. Перед ним пользователь подтверждает действие (UC-42), при необходимости файл загружают заново.
- Prod не меняется: S3 у провайдера VPS, тот же S3 API.

## Рассмотренные варианты

- **MinIO из исходников или зеркала:** сохраняет прежнюю схему, но сборка и неофициальные образы без обновлений безопасности.
- **RustFS, SeaweedFS:** Apache 2.0, ближе к MinIO по возможностям, но тяжелее по устройству или моложе. Для локальной работы избыточны.
- **Ceph RGW:** слишком тяжёл для ноутбука.

## Последствия

- Проверено на Garage v2.5.0: presigned PUT и GET, `HEAD`, `GET Range: 0-4100`, `Content-Disposition`, удаление объекта.
- Клиент `@aws-sdk/client-s3` создаём с `forcePathStyle: true` и `requestChecksumCalculation: "WHEN_REQUIRED"`: без последнего presigned PUT получает 400 из-за контрольной суммы пустого тела.
- Garage распространяется под AGPL v3. Мы используем его только как локальный инструмент и не распространяем.
- Потерянный по нашей ошибке объект восстановить нельзя. Для MVP риск принят. Если появятся данные, которые нельзя загрузить повторно, версионирование включается в настройках бакета у провайдера, без изменений в коде.
