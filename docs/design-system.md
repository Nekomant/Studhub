## 2. Решения

| # | Решение | Почему |
|---|---|---|
| ДС-1 | **Стиль «тёплый рабочий блокнот».** Тёплый светлый фон («бумага»), карточки с рамкой без теней, радиусы 10–14 px, средняя плотность | Главный конкурент: таблицы, блокнот и календарь (концепция §1). Стиль ежедневника отличает продукт от шаблонных SaaS и близок преподавателям языков. Плотность и чёткие цифры взяты от строгого рабочего инструмента |
| ДС-2 | **Шрифты: Nunito 800 для заголовков, Manrope для текста.** Шрифтов с засечками нет | Владельцу нужны жирные округлые заголовки «как указатели в аэропорту» и лёгкий основной текст. У обоих шрифтов есть кириллица, у Manrope есть табличные цифры (Nunito набирает только заголовки), лицензия OFL |
| ДС-3 | **Вес 300 только для чисел от 20 px.** Основной текст Manrope 400, размер 15 px | Тонкий штрих в 14–16 px на обычных экранах выглядит серым и размытым. Manrope широкий, при 16 px в строку телефона влезает меньше |
| ДС-4 | **Акцент «слива» `#6B3F69`** | Не спорит с цветами статусов: зелёный, оранжевый, жёлтый и красный заняты смыслом. Контраст с белым текстом 8,3:1 |
| ДС-5 | **Красный только для долга, ошибок и необратимых действий** | Долг ученика должен быть заметен сразу |
| ДС-6 | **Две темы и переключатель «Оформление» в Э-17:** «Как в системе» (по умолчанию), «Светлая», «Тёмная». Выбор хранится на устройстве | Уроки и итоги часто вечером, светлый экран слепит. Хранение на устройстве не требует API и работает без сети |
| ДС-7 | **Основа: shadcn/ui, наши токены подставлены в его переменные** (§8) | Стек уже выбран (ТД §3). Тема переносится на shadcn-vue без изменений |
| ДС-8 | **Шрифты раздаём сами:** `woff2` с подмножествами latin и cyrillic в `packages/ui-tokens` | ТД §9: никаких внешних CDN. Google Fonts используются только в артефактах-макетах |

## 3. Цвета

Имена токенов совпадают с CSS-переменными: `paper` → `--paper`. Контраст проверен расчётом по WCAG 2 в обеих темах: основной текст от 12:1, второстепенный от 4,8:1, текст статусов на своём фоне от 5,3:1, рамки полей `line-strong` от 3,4:1.

| Токен | Светлая | Тёмная | Где используется |
|---|---|---|---|
| `paper` | `#F6F2EA` | `#1F1B18` | Фон страницы и экрана |
| `surface` | `#FFFDF8` | `#2A2521` | Карточки, строки списков, шторки, модальные окна |
| `sunken` | `#EFE9DF` | `#24201C` | Фон полей ввода, подложка сегментов, заглушки при загрузке |
| `line` | `#E6DED0` | `#3A332D` | Рамки карточек и разделители строк |
| `line-strong` | `#857766` | `#837666` | Рамка полей ввода, чекбоксов и переключателей |
| `ink` | `#2B2622` | `#EDE6DC` | Основной текст и заголовки |
| `ink-muted` | `#6E6359` | `#A89C8F` | Второстепенный текст: «у ученика 22:00», даты, подписи, подсказки |
| `plum` | `#6B3F69` | `#C893C4` | Заливка главной кнопки, активная вкладка, отметки |
| `plum-hover` | `#5A3358` | `#D6A8D2` | Наведение и нажатие на `plum` |
| `on-plum` | `#FFFDF8` | `#2A1828` | Текст на `plum`. В тёмной теме слива светлая, текст на ней тёмный |
| `plum-soft` | `#EFE3EE` | `#4A2E48` | Активная вкладка навигации, статус «Идёт», выбранная строка |
| `plum-ink` | `#6B3F69` | `#D9AED5` | Ссылки, текстовые кнопки, текст на `plum-soft` |
| `focus` | `#6B3F69` | `#D9AED5` | Кольцо фокуса: 2 px сплошное, отступ 2 px |
| `done-bg` / `done-ink` | `#E3EFE3` / `#2D5A2E` | `#24402A` / `#9FD0A0` | «Проведён», оплата «+3 000 ₽» |
| `charge-bg` / `charge-ink` | `#F8E3D6` / `#8A3D14` | `#4A2D1C` / `#F0B48A` | Платные отмены: «Поздняя отмена», «Не пришёл» |
| `pending-bg` / `pending-ink` | `#F7E9CC` / `#7A4E0B` | `#4A3A1A` / `#EBC77F` | Ждёт действия: «Перенесён без даты», пересечение уроков |
| `debt-bg` / `debt-ink` | `#F8E1DD` / `#A33A2A` | `#4A2420` / `#F08C7A` | Долг и ошибки |
| `idle-bg` / `idle-ink` | `#EDE7DD` / `#5E554C` | `#353029` / `#C9BEB1` | Отмены без списания: «Отмена вовремя», «Отменил я» |
| `danger` / `on-danger` | `#A33A2A` / `#FFFDF8` | `#E58A78` / `#2A1310` | Кнопка необратимого действия и текст на ней |
| `scrim` | `rgba(43, 38, 34, 0.40)` | `rgba(0, 0, 0, 0.55)` | Затемнение под шторкой и модальным окном |

Правила:

- Фон экрана `paper`, карточки `surface`, поля `sunken`. Карточку отделяет рамка `line`, тени только у слоёв поверх экрана.
- Одна главная кнопка (`plum`) на экран или шторку.
- Цвета статусов не используются как акцент и для украшения.
- Статус всегда передаётся словом, цвет только помогает.
- Прозрачность для приглушения текста не используем, только `ink-muted`.

## 7. Компоненты и правила

Превью и правила каждого компонента есть в артефакте дизайн-системы. Кратко:

- **Кнопка:** главная (`plum`), вторичная (рамка `line-strong`), текстовая (`plum-ink`), опасная (`danger`, только финальное подтверждение уровня 2 по П-5). Пока команда ждёт сервер, на кнопке «Сохраняется…» (П-1).
- **Строка урока:** время, имя, подпись, бейдж; у проведённого урока сумма списания. Отменённый урок приглушён, но остаётся в списке.
- **Карточка «Следующий урок»:** подпись и статус, имя, время и «у ученика», план, ДЗ, баланс, кнопки «Открыть урок» и «Подключиться».
- **Деньги:** долг всегда со словом «Долг» и цветом `debt-ink`; оплата `done-ink` со знаком «+»; списание `ink` со знаком «−» (настоящий минус).
- **Поле ввода:** подпись над полем, ошибка под полем цветом `debt-ink`, пересечение уроков плашкой `pending-bg` (не ошибка).
- **Плашки П-7:** на всю ширину, без радиуса: удаление аккаунта `debt-bg`, нет сети `idle-bg`, новая версия и часовой пояс `plum-soft`.
- **Тост:** цвета `ink` и `paper` меняются местами.
- **Шторка:** `surface`, верхние углы `radius-l`, ручка, главная кнопка закреплена внизу. На компьютере панель справа шириной 420 px.
- **Навигация:** на телефоне нижняя панель, активная вкладка с капсулой `plum-soft`; на компьютере боковая панель, активный пункт с фоном `plum-soft`.
- **Иконки:** lucide, контурные, толщина линии 1,75, 20 px (16 px в строках). Без подписи только «Назад», «Закрыть», «⋯», поиск.
- **Движение:** наведение 150 мс, шторка 250 мс; при `prefers-reduced-motion` без сдвига.
- **Тексты:** на «вы», регистр как в предложении, кнопки с глагола, без эмодзи, «успешно» и восклицательных знаков.

## 8. Как токены ложатся на shadcn/ui

| Переменная shadcn | Токен |
|---|---|
| `--background` / `--foreground` | `paper` / `ink` |
| `--card`, `--popover` | `surface` |
| `--primary` / `--primary-foreground` | `plum` / `on-plum` |
| `--secondary`, `--muted`, `--accent` | `sunken` |
| `--muted-foreground` | `ink-muted` |
| `--destructive` | `danger` |
| `--border` / `--input` | `line` / `line-strong` |
| `--ring` | `focus` |
| `--radius` | `radius-m` (10 px) |

Тёмная тема включается классом `dark` на `<html>`. Без класса, как и с классом `light`, действует светлая тема: CSS пакета не учитывает `prefers-color-scheme`. Значение «Как в системе» ставит класс скриптом по `prefers-color-scheme` и следит за его изменением (SH-022).

В теме Tailwind радиусы называются `rounded-sm` (6 px), `rounded-md` (10 px), `rounded-lg` (14 px) и `rounded-pill`, как ждут компоненты shadcn/ui. Стили текста из §5 подключаются классами `title-xl` … `figure`, табличные цифры классом `tabular`. Шрифты в пакете содержат подмножества latin и cyrillic. Знака рубля ₽ (U+20BD) в них нет, он выводится системным шрифтом.

Стандартная палитра Tailwind в теме сброшена (`--color-*: initial`), но `white` и `black` сохранены (`--color-white: #fff`, `--color-black: #000`): shadcn/ui использует `bg-black/50` для оверлея Dialog и `text-white`.
